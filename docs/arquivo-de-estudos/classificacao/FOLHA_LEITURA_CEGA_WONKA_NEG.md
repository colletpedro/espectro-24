> **Fotografia e efeitos visuais criticados**

## A pergunta

Para cada uma das 32 reviews abaixo, decida se ela **sustenta** o tema acima —
ou seja, se ela afirma que a fotografia e/ou os efeitos visuais do filme são
ruins/artificiais/feios — usando **um** destes quatro valores:

| valor | quando usar |
|---|---|
| **sustenta** | a review afirma o que o tema afirma — critica a fotografia, o CGI, os efeitos visuais, os cenários ou a estética visual do filme |
| **não sustenta** | a review não faz essa afirmação — seja porque não fala do assunto, seja porque fala de outra coisa (música, roteiro, atuação, ritmo…) sem tocar em visual |
| **contradiz** | a review afirma o **oposto** — elogia a fotografia, o CGI, os efeitos visuais ou a estética do filme |
| **não sei julgar** | a review está num idioma que você não domina o suficiente para decidir com confiança. Marcar isto é um resultado válido, não uma falha — é preferível a chutar |

**Regras:**
- Julgue no idioma original da review — não é preciso traduzir para decidir,
  mas se precisar de ajuda de tradução e ainda ficar em dúvida, use "não sei
  julgar".
- Um comentário vago ("o filme é ruim", "não gostei") sem menção a
  visual/CGI/fotografia/cenário/cor é **não sustenta**, mesmo que o veredito
  geral seja muito negativo.
- Uma menção de passagem ao visual que não critica nem elogia (ex.: só
  descreve um elemento visual sem julgá-lo) é **não sustenta**.
- Anote, se quiser, o trecho que te fez decidir — não é obrigatório, mas ajuda
  na comparação depois.
